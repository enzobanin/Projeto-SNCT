# Projeto-SNCT
Este repositório possui o código do projeto prático a ser ministrado na SNCT

## Clonando o repositório
Para rodar esse projeto, clone este repositório, copiei e já no VSCODE clique em "Clone Git Repository"
insira a cópia do repositório, salve onde quiser

## Rodando o projeto
Clique no arquivo fora das pastas, o "index.html", depois na barra no canto superior esquerdo clique em "Run" e
depois em "Start Debugging", pronto, seu projeto estará rodando em seu navegador!
